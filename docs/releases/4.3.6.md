# Fearless Android 4.3.6 (238)

This release starts from the integrated 16 November source at
`ee8a51738efd947a4e6bc53998964d361c0a9a7e` and adds the Liberland fallback
node from `fbab94fc66a5110c3a1fa4cc8d45489d614d54e1`. The remote configuration
manifest is signed with the existing release key. It includes the one-list
wallet home, Receive deposit subscriptions, corrected minimum liquidity
amounts, synchronized unbond fee review and the integrated coverage-campaign
bug fixes.

The release ledger records `4.3.6+238=84`. This release retains database
schema 84 and every supported migration; it does not change the schema.

Release validation also caught a connection-status race: losing the network
while the recovery banner was visible could leave it saying “Connected”. The
banner now restores “Connecting…” and ignores an obsolete hide animation.

Builds, tests, artifact integrity checks and upgrade results run locally.
The exact final source commit, signed AAB hash and full logs are retained in
`output/production-release-20261117/android/` in the parent workspace.
No hosted CI result is a release prerequisite.

Google Play publication is recorded separately after the local gates pass.
