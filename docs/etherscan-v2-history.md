# Android Etherscan-family history migration

The bundled Ethereum, BNB Smart Chain (mainnet/testnet), Sepolia and Polygon history routes use `https://api.etherscan.io/v2/api` with an explicit EVM `chainid`. The Etherscan account key supplied through `FL_ANDROID_ETHERSCAN_API_KEY` is shared across those routes; old BscScan and PolygonScan V1 keys are no longer read. Etherscan [deprecated V1 on 2025-08-15](https://info.etherscan.com/etherscan-api-v1-will-be-fully-deprecated-by-15th-august-2025/), and its [V2 API](https://docs.etherscan.io/api-reference/endpoint/txlist) requires the chain ID and unified key.

The current [Etherscan chain list](https://api.etherscan.io/v2/chainlist) includes IDs `1`, `56`, `97`, `11155111`, `137`, and `10`. Goerli (`5`) and Polygon Mumbai (`80001`) are absent; the Android history source reports those retired testnets as unsupported instead of trying their old V1 hosts. OP Mainnet (`10`) currently uses the separate OKLink history route; the Etherscan source can use V2 for it only if its configured history type and URL are deliberately changed. Independent Etherscan-compatible explorers such as Oasys continue to use their own configured HTTPS endpoint without receiving the unified Etherscan key.

The source binds each official chain ID to its own legacy URL or the canonical V2 URL, preventing a mismatched history config from being silently redirected. It keeps the existing 1,000-record fetch window and pages forward when that window is full. A missing unified key, provider `NOTOK` response, rate limit, malformed success payload, or network failure is an error. Only an explicit `No transactions found` response is an empty page. Failed refreshes leave cached operations and the paging cursor intact, allowing the existing error/retry and explorer flow to recover. The key is embedded in distributed clients, so the release operator must provision a valid Etherscan V2 key and monitor its quota; its value is not a private wallet secret.

Before release, test the exact Play-signed artifact with the provisioned key on Ethereum, BNB Smart Chain, Polygon and Sepolia/BNB testnet. Check native and token history, a genuinely empty address, rate-limit and invalid-key errors, retry after outage, cache preservation, and explorer links. These live-provider checks and provider account provisioning remain release gates; unit tests do not establish them.
